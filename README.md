# 📊 Netflix Data Analysis Dashboard

## 🚀 Project Overview
This project is an interactive Streamlit dashboard that analyzes Netflix movies and TV shows dataset.  
It provides insights like content distribution, trends, and visual analytics.

---

## 📂 Features

- 📄 Dataset preview
- 🧹 Data cleaning (handling missing values)
- 📊 KPIs (Total Movies, TV Shows, etc.)
- 🎛️ Interactive filters
- 📈 Visualizations using Plotly
- 📅 Release Year analysis
- 🌍 Country-wise analysis
- 🎭 Genre analysis

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Matplotlib
- Seaborn
